# v0.1.1 — 외부 접속 진단 테스트

기준 수정: `97d97c2`의 방장 IP/포트 전달 수정 포함.
동일 PC/동일 공인 IP에서 서버와 방장을 실행하고, 외부 참가자가 PVE/PVP 로딩 후 로비로 복귀하는 문제를 시험하기 위한 버전입니다.

## 포함된 변경

- `gameHosts`로 방장의 공인/VPN IPv4와 외부 전투 포트를 지정합니다.
- 외부 참가자에게 루프백 주소를 전달하는 시작을 차단하고, 잘못된 포트와 실패 응답을 구분합니다.
- 전투 시작, 방장 리스닝 응답, 참가자에게 전달한 주소, 참가자 응답을 시간·방·연결 번호로 추적합니다.
- 제어 TCP 오류/종료와 클라이언트 퇴장 요청을 구분할 로그를 추가합니다.
- 서버 시작 시 버전과 Node.js 버전을 출력합니다.

이번 추가 진단 작업은 게임 패킷 내용이나 진행 순서, 타임아웃을 바꾸지 않습니다.

## 적용 및 테스트

1. 기존 설치와 `config/server.json`, `database/config.json`을 백업합니다.
2. 릴리스 소스를 적용하고 기존 로컬 설정과 게임 파일을 유지합니다. 새 설치라면 `npm ci`로 의존성을 설치합니다.
3. `gameHosts`의 방장 로그인 아이디와 실제 공인 IP를 설정합니다. 같은 PC라면 `publicHost`와 같은 공인 IP를 사용할 수 있습니다.
4. `host-ready` 로그의 실제 전투 포트를 방장 PC로 포워딩하고 방화벽을 확인합니다.
5. 서버를 재시작해 `[release] version=0.1.1`을 확인한 뒤 외부 참가자와 PVE/PVP를 각각 시험합니다.

세부 설정 및 로그 저장 방법은 [한국어 네트워크 설정 안내](https://github.com/dkwkdk1136/test2/blob/v0.1.1/docs/NETWORK_SETUP.ko.md)에 있습니다. ZIP 내부의 `docs/NETWORK_SETUP.ko.md`에서도 읽을 수 있습니다.
ZIP에는 비밀번호가 들어 있는 로컬 설정, node_modules, 게임 클라이언트/맵 파일이 포함되지 않습니다.
데이터베이스 마이그레이션이나 새 게임 파일은 이 릴리스에서 요구하지 않습니다.

## 검증과 제한

- 자동 테스트 21개와 회귀 테스트 스크립트 6개로 검증합니다.
- 실제 해외 접속, 공유기·방화벽·CGNAT, 게임 전체 플레이는 사용자 재시험이 필요합니다.
- 자동 포트 개방/NAT 우회/전투 중계 기능은 포함하지 않습니다.
- 공유할 로그에서는 실제 IP·계정 정보와 기존 로그의 인증 데이터를 제거하세요.
