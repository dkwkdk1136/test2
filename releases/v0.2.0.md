# Metal Rage Online v0.2.0

## 변경 사항
- 게임 내 회원가입·비밀번호 인증과 TLS 연결 기능을 유지하면서 Node.js 설치와 CMD 창이 필요 없는 Windows 11 x64 런처를 제공합니다.
- 런처가 게임 실행 파일의 전체 경로에만 SEHOP 비활성화를 적용하고 확인합니다. 설정은 게임 종료 후에도 해당 경로에 유지됩니다. 시스템 전체 설정은 변경하지 않습니다.
- 로비 뒤로가기 응답과 서버 목록 재전송을 추가했습니다. 서버 이름은 `MO_Server_1`입니다.
- 경기 종료 시 XP·포인트·승패·킬/데스·기체 성장을 DB에 저장합니다. 중복 정산 방지와 실패한 정산의 다음 시작 시 재처리를 포함합니다.
- PvE는 1킬당 1 XP·2포인트, 최대 100킬만 보상에 반영합니다. 솔로 PvE는 합계의 75%입니다. 10분 다인 PvE 클리어 기준 100킬과 1,000킬 모두 800 XP·1,600포인트입니다.
- 클라이언트 스레드 알림 콜백 호환성 패치 도구와 오프라인 검증 도구를 제공합니다. 이전 시작 충돌 패치는 폐기 상태로 명시했습니다.

## 설치
- `MetalRage-Server-v0.2.0.zip`: 서버 소스입니다. 기존 DB와 개인 설정·인증서·pending-rewards를 백업·보존하고 `npm ci`, `npm run rewards:migrate` 후 서버를 직접 재시작하세요. 기존 DB를 초기화하지 마세요.
- `MetalRage-Launcher-v0.2.0-win-x64.zip`: 기존 클라이언트 루트(data 폴더 옆)에 덮어쓰는 런처 패키지입니다. 전체 게임과 패치된 게임 EXE는 포함하지 않습니다. `Play Metal Rage Online.exe`로 실행하세요. Node.js/.NET 별도 설치가 필요 없으며 관리자 권한 요청이 표시됩니다.
- 런처에 포함된 공개 CA와 TLS 설정은 현재 운영 서버용입니다. 서버 개인키·DB 비밀번호·회원 정보는 포함하지 않습니다.
- 원본 게임 실행 파일용 호환성 패치 재생성 방법은 `tools/client-stability/REVISION2.ko.md`, 보상 수치와 제한은 `docs/REWARDS.ko.md`를 참고하세요.

## 검증 및 남은 확인
- 서버 자동 테스트·프로토콜 회귀 테스트 통과. 임시 계정으로 실제 MySQL 저장·동시 중복 지급 방지·레벨 상승을 확인했습니다.
- 네이티브 런처 빌드와 전투 결과 수신 패킷 오프라인 검증을 완료했습니다.
- 실제 게임에서 보상 결과창·재접속 후 저장, SEHOP 적용 및 전투 프리징 개선 여부는 운영 환경 확인이 필요합니다. 프리징 완전 해결을 보장하는 릴리즈는 아닙니다.
- 방장 보고 기반 전투 구조이며 완전한 부정행위 검증과 AFK 탐지는 아직 지원하지 않습니다.
